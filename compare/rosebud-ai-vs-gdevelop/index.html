Rosebud AI vs GDevelop: a playable game this weekend, or a no-code engine

Pick Rosebud AI if you want a playable browser game from a prompt this weekend, including assets, NPCs and multiplayer. Pick GDevelop if the game may grow, and you want a no-code engine with an AI assistant rather than another prompt tool.

Questions

Which gets a game online this weekend?

Rosebud AI is #1: from a prompt to a playable browser game, with assets, NPCs and multiplayer. GDevelop is #3, a no-code engine with an AI assistant, a good step if the game grows.

What do they cost?

Rosebud lists free and paid plans, with no dollar amount. GDevelop's price is not listed (see its pricing page). Do not treat a missing number as free.

What if I want the project to be mine?

The #2 pick in that ranking is a coding agent plus Three.js: more flexible, and the project is yours. Prompt-to-game tools are the easiest way in. StackPodium does not describe a code export for Rosebud AI or for GDevelop.
