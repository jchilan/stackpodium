Questions

Which has more apps?

Zapier, with a catalogue of over 8,000 apps. It ranks #3. n8n ranks #1 as the base when the agent has to act inside your tools.

How does billing differ?

n8n is free when you self-host. Cloud Starter is €20/mo, billed annually. Zapier bills per task, so watch your volume. StackPodium does not list Zapier's entry price.

Which can I run myself?

n8n. It is source-available under the fair-code Sustainable Use License, and the Community edition is free to self-host. n8n does not call that license open source. Zapier is a hosted catalogue.
