Case 08

A custom agent, with code

You need full control of the agent loop, its memory and its tools.

  1. Gold1
    LangGraphOpen source

    Agents as stateful graphs. The pick for complex flows that have to be reliable.

  2. Silver2
    CrewAIOpen source

    Teams of agents with roles. Quicker to start than LangGraph.

  3. Bronze3
    OpenAI Agents SDKOpen source

    A lightweight SDK if you already work with OpenAI models.

If n8n (previous case) can do it, start there. Move to code when the visual flow falls short.
