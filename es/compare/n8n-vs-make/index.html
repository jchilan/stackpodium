n8n vs Make: autoalojar o el constructor visual más fácil

Elige n8n si el agente tiene que actuar dentro de tus herramientas y quieres una base con código disponible que puedas autoalojar. Elige Make si quieres el constructor visual más fácil para un primer agente y no necesitas autoalojar.

Preguntas

¿Cuál es más fácil?

Make es el constructor visual más fácil para un primer agente y queda nº 2. n8n queda nº 1 cuando el agente tiene que actuar dentro de tus herramientas.

¿Puedo autoalojarlo?

n8n es gratis para autoalojar bajo la Sustainable Use License, fair-code. n8n no llama a esa licencia código abierto. El Starter en la nube es 20 €/mes, facturado al año. StackPodium no lista un precio de Make.

¿Y si no quiero escribir código?

Los dos están en el ranking sin código. Make es el arranque visual más fácil. Pasa a n8n cuando el agente tenga que actuar dentro de tus herramientas. Si el flujo visual no basta, el ranking siguiente es un agente a medida, con código.
