Perguntas

Qual coloca um jogo no ar neste fim de semana?

O Rosebud AI é o #1: do prompt ao jogo jogável no navegador, com assets, NPCs e multiplayer. O GDevelop é o #3, um motor sem código com assistente de IA, um bom passo se o jogo crescer.

Quanto custam?

O Rosebud lista planos grátis e pagos, sem um valor em dólares. O preço do GDevelop não está listado (veja a página de preços). Não trate um número ausente como grátis.

E se eu quiser que o projeto seja meu?

A escolha #2 nesse ranking é um agente de código mais Three.js: mais flexível, e o projeto é seu. As ferramentas de prompt para jogo são a entrada mais fácil. O StackPodium não descreve exportação de código para o Rosebud AI nem para o GDevelop.
