隐私说明

StackPodium 在西班牙运营。如有任何隐私方面的问题或请求，请发邮件至 joanpau.ch22@gmail.com。

本网站

  • 本站没有账户，也没有表单，我们不设置任何自有 Cookie。
  • 我们不使用统计分析或广告追踪工具。
  • 本站托管在 GitHub Pages。与任何托管服务一样，GitHub 会收到你的 IP 地址，并可能出于安全和运行需要将其保存在服务器日志中。
  • 字体从 Google Fonts 加载，因此打开页面时你的浏览器会连接 Google 的服务器。

邮件订阅

  • 订阅在我们的邮件服务商 beehiiv（总部位于美国）的页面上完成。beehiiv 会保存你的邮箱地址，并记录打开和点击情况。
  • 我们只用你的地址发送邮件，不会出售，也不会提供给赞助商。
  • 每封邮件都有退订链接。你也可以要求我们删除你的数据。

外部链接

我们会链接到所排名的工具。这些网站有各自的隐私政策。如果将来加入联盟链接，会明确标注。

你的权利

根据 GDPR，你可以写信到上述地址，要求查阅、更正或删除你的数据，或反对其使用。你也可以向西班牙数据保护机构（AEPD）投诉。
