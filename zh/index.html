场景 01

零编程经验，做我的第一个网页应用

你有一个想法，但没有任何经验。你想把它描述出来，今天就看到能运行的东西。

  1. 1
    LovablePro $25/月

    最常被推荐给非技术创始人：生成干净的 React 代码，并已接好 Supabase。

  2. 2
    BoltPro $25/月

    免费额度最慷慨，适合先试后买，而且可以自选框架。

  3. 3
    ReplitCore $20/月

    功能最全、入门价最低，但从第一分钟起就要面对代码：更强大，也更难上手。

Lovable 按积分计费，Bolt 按 token 计费，两者无法直接比较。订阅前，先在两边各做同一个小功能试试。

场景 02

带登录、数据库和支付的 SaaS MVP

你想向真实用户收费，需要身份验证、持久化数据和支付通道。

  1. 1
    LovablePro $25/月

    对话式全栈开发，内置 Supabase。一个套餐可供整个团队使用。

  2. 2
    ReplitCore $20/月

    代理、编辑器、终端和部署都在一处。后端有自定义逻辑时更合适。

  3. 3
    BoltPro $25/月

    做完整原型很快；但按成员收费，团队使用成本较高。

还需要搭配：Supabase 负责数据库和登录，Stripe 负责支付。

场景 03

快速做出精致的界面或落地页

产品或想法已经有了，只差好看。

  1. 1
    v0Plus $30/用户/月

    界面质量最好，React 代码最干净。为部署到 Vercel 而设计。

  2. 2
    LovablePro $25/月

    设计很好，还能一路做成完整应用。

  3. 3
    BoltPro $25/月

    够用，但界面不如 v0 精致。

v0 最初只做前端。2026 年 2 月增加了 Git、编辑器和数据库连接，但后端能力仍然偏弱。

场景 04

手机应用

你想要能安装在 iOS 和 Android 上的应用，而不是自适应网页。

  1. 1
    BoltPro $25/月

    用 Expo 生成应用，是从一句提示到 iOS 和 Android 的最短路径。

  2. 2
    Emergent查看价格

    如果同一个项目既要网页又要移动端，值得看看这个选择。

  3. 3
    ReplitCore $20/月

    如果你更想掌控代码，这是可靠的备选。

Lovable 不支持原生移动端。如果你已经在用它，得到的会是自适应网页应用。

场景 05

用 AI 编辑器认真写代码

你懂一些代码，或已有现成项目，想更快，但不想失去掌控。

  1. 1
    Cursor起价 $8/月

    AI 编辑器的标杆，基于 VS Code。自动补全、多文件编辑和代理。

  2. 2
    GitHub CopilotPro $10/用户/月

    直接在你现有的编辑器里使用，IDE 支持最广。

  3. 3
    Devin DesktopPro $20/月

    即原来的 Windsurf。编辑器思路与 Cursor 相同。列出的 Pro 为 $20/月。

Cursor 的个人套餐为 Plus $8、Premium $30、Super $100 和 Ultra $200 每月。用量是每周刷新的共享额度池。从 Premium 起，第三方模型另行计费。

场景 06

把耗时任务交给编程代理

你想把一整项任务（重构、加功能、修测试）交出去，然后只审查结果。

  1. 1
    Claude Code包含在 Pro 和 Max 中

    在终端中运行、可处理整个代码库的代理。复杂推理方面领先。

  2. 2
    Codex包含在 ChatGPT 套餐中

    OpenAI 的同类产品。包含在 ChatGPT 套餐中，也可用 API 密钥。

  3. 3
    Gemini CLI查看价格

    Google 的终端方案。

很多开发者日常用编辑器（上一个场景），大任务再交给终端代理。

场景 07

不写代码，做一个自动处理任务的代理

你想让它替你读邮件、更新表格或回复客户。

  1. 1
    n8n可免费自托管 · 云端年付起价 €20/月

    当代理需要在你的各种工具里执行操作时，这是最好的基础。源代码可获取，采用 fair-code 的 Sustainable Use License，并带原生 AI 节点。

  2. 2
    Make免费 · Core 起价 $9/月

    做第一个代理时最容易上手的可视化搭建工具。

  3. 3
    Zapier查看价格

    应用目录最广，超过 8,000 个。按任务计费，注意用量。

以自然语言描述代理为主的替代选择：Lindy 和 Gumloop。

场景 08

用代码做一个定制代理

你需要完全控制代理的循环、记忆和工具。

  1. 1
    LangGraph开源

    把代理建模为有状态的图。适合必须可靠的复杂流程。

  2. 2
    CrewAI开源

    按角色分工的代理团队。比 LangGraph 上手更快。

  3. 3
    OpenAI Agents SDK开源

    如果你已经在用 OpenAI 的模型，这是一个轻量的 SDK。

如果 n8n（上一个场景）能解决，就从那里开始。可视化流程不够用时再转向代码。

场景 09

这个周末做出一个能玩的网页游戏

你想把一个想法变成可以用链接发给朋友的东西。

  1. 1
    Rosebud AI有免费和付费套餐

    从提示词到可玩的网页游戏，素材、NPC 和多人联机都包含在内。

  2. 2
    编程代理 + Three.js取决于所用代理

    更灵活，项目也完全归你。Three.js 是浏览器 3D 的常用基础。

  3. 3
    GDevelop查看价格

    内置 AI 助手的无代码引擎。游戏规模变大时是不错的下一步。

“提示词生成游戏”类工具最容易入门。编程代理更自由，但要多花功夫。

场景 10

内部工具或数据看板

给团队或生意用的看板、小型 CRM 或表单。

  1. 1
    ReplitCore $20/月

    混合式编辑器加终端：更容易改造，也更容易连接你的数据。

  2. 2
    Base44查看价格

    擅长数据密集的业务应用。如果追求像素级设计，它不是首选。

  3. 3
    LovablePro $25/月

    外观比逻辑更重要时的备选。

如果只是展示指标，一张连接好的电子表格通常就够了。需要有人录入数据时，再去做工具。

评分方法

每个工具都在一个具体场景内评分，而不是泛泛比较。本版本的名次来自官方文档和已发表的对比文章。我们自己的实测（在每个工具里做同一个项目）将在下一版加入，并会明确标注。

  • 40%

    场景内的结果

    能否不绕弯路，做出对这个目标真正可用的东西？

  • 20%

    真实成本

    入门价格，以及账单是否可预期。按积分或 token 计费会扣分。

  • 15%

    可迁移性

    能否导出代码并在别处继续，还是会被锁定？

  • 15%

    学习曲线

    对该场景的目标用户来说，多久能得到第一个结果。

  • 10%

    成熟度

    产品稳定性、文档和社区。

影响排名的变化

只有当一次发布或变动会影响你该选哪个工具时，我们才会发布。

  • 2026年11月

    Cursor 调整套餐

    价格页上的个人套餐为 Plus $8、Premium $30、Super $100 和 Ultra $200 每月。该页没有列出 $20 的 Pro。 来源: Cursor

  • 2026年6月

    Windsurf 更名为 Devin Desktop

    Cognition 停用了 Windsurf 品牌。现有套餐和扩展照常沿用；Pro 套餐此前已从 $15 涨到 $20。 来源: Noqta

  • 2026年2月

    v0 不再只做前端

    新增了 Git、编辑器和数据库连接。面向新用户的公开付费套餐是 Plus，每位用户每月 $30，并含每月 $30 额度。$20 的 Premium 不再向新用户提供。Replit Core 为 $20/月，按年计费则为 $18/月。 来源: v0
