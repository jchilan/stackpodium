Case 01

My first web app, with no coding experience

You have an idea and zero experience. You want to describe it and see something working today.

  1. 1
    LovablePro $25/mo

    The most recommended pick for non-technical founders: it generates clean React with Supabase already connected.

  2. 2
    BoltPro $25/mo

    The most generous free plan for trying before you pay, and you choose the framework.

  3. 3
    ReplitCore $20/mo

    The most complete and the lowest entry price, but you see the code from minute one: more power, steeper curve.

Lovable bills in credits and Bolt in tokens. They aren't comparable; try the same small feature in both before subscribing.

Case 02

A SaaS MVP with login, a database and payments

You want to charge real users. You need authentication, persistent data and a payment provider.

  1. 1
    LovablePro $25/mo

    Conversational full-stack with Supabase built in. One plan covers the whole team.

  2. 2
    ReplitCore $20/mo

    Agent, editor, terminal and deployment in one place. Better when your backend has its own logic.

  3. 3
    BoltPro $25/mo

    Fast for the complete prototype; it charges per member, so it gets expensive for a team.

Parts you'll add: Supabase for the database and login, and Stripe for payments.

Case 03

A polished interface or landing page, fast

You already have the product or the idea. You need it to look good.

  1. 1
    v0Plus $30/mo

    The best interface quality and the cleanest React. Built to deploy on Vercel.

  2. 2
    LovablePro $25/mo

    Very good design, and it lets you carry on to the full app.

  3. 3
    BoltPro $25/mo

    Gets the job done, with less polished interfaces than v0.

v0 started as frontend-only. In February 2026 it added Git, an editor and database connections, but it is still lighter on backend.

Case 04

A mobile app

You want something installable on iOS and Android, not a responsive website.

  1. 1
    BoltPro $25/mo

    Builds apps with Expo, the shortest path from a prompt to iOS and Android.

  2. 2
    EmergentSee pricing

    The alternative to look at if you need web and mobile from the same project.

  3. 3
    ReplitCore $20/mo

    A solid second choice if you prefer to control the code.

Lovable has no native mobile support. If you already work there, expect a responsive web app.

Case 05

Serious coding with an AI editor

You know some code or have an existing project. You want to go faster without losing control.

  1. 1
    CursorFrom $30/mo

    The reference AI editor, built on VS Code. Autocomplete, multi-file edits and agents.

  2. 2
    GitHub CopilotSee pricing

    Works inside the editor you already use and has the widest IDE support.

  3. 3
    Devin DesktopPro $20/mo

    The former Windsurf. The same approach as Cursor for less money.

Watch Cursor's usage billing: model usage is drawn from a pool and extra spend can surprise you.

Case 06

Hand long tasks to a coding agent

You want to give it a whole task (refactor, add a feature, fix tests) and review the result.

  1. 1
    Claude CodeIncluded in Pro and Max

    A terminal agent that works across your whole repository. Leads on complex reasoning.

  2. 2
    CodexIncluded in ChatGPT plans

    OpenAI's equivalent. Included in ChatGPT plans, or usable with an API key.

  3. 3
    Gemini CLISee pricing

    Google's option for the terminal.

Many developers pair an editor (previous case) for daily work with a terminal agent for the big tasks.

Case 07

An agent that automates a task, without code

You want something to read emails, update a sheet or answer customers for you.

  1. 1
    n8nFree self-hosted · cloud from $24/mo

    The best base when the agent has to act inside your tools. Open source with native AI nodes.

  2. 2
    MakeSee pricing

    The easiest visual builder for a first agent.

  3. 3
    ZapierSee pricing

    The broadest catalogue, over 8,000 apps. It bills per task, so watch your volume.

Alternatives built around describing the agent in plain language: Lindy and Gumloop.

Case 08

A custom agent, with code

You need full control of the agent loop, its memory and its tools.

  1. 1
    LangGraphOpen source

    Agents as stateful graphs. The pick for complex flows that have to be reliable.

  2. 2
    CrewAIOpen source

    Teams of agents with roles. Quicker to start than LangGraph.

  3. 3
    OpenAI Agents SDKOpen source

    A lightweight SDK if you already work with OpenAI models.

If n8n (previous case) can do it, start there. Move to code when the visual flow falls short.

Case 09

A playable browser game this weekend

You want to go from an idea to something you can send a friend as a link.

  1. 1
    Rosebud AIFree and paid plans

    From prompt to playable browser game, with assets, NPCs and multiplayer included.

  2. 2
    Coding agent + Three.jsDepends on the agent

    More flexible, and the project is yours. Three.js is the usual base for 3D in the browser.

  3. 3
    GDevelopSee pricing

    A no-code engine with an AI assistant inside. A good step if the game grows.

Prompt-to-game tools are the easiest way in. Coding agents give more freedom in exchange for more work.

Case 10

An internal tool or a data dashboard

A dashboard, a small CRM or a form for your team or business.

  1. 1
    ReplitCore $20/mo

    Hybrid editor and terminal: easier to adapt and to connect to your data.

  2. 2
    Base44See pricing

    Strong on data-heavy business apps. Not the pick if you want pixel-perfect design.

  3. 3
    LovablePro $25/mo

    Second choice when looks matter more than logic.

To only display metrics, a connected spreadsheet is often enough. Build the tool when people need to enter data.

How we score

Each tool is scored inside one specific use case, never in general. The positions in this version come from official documentation and published comparisons. Our own tests, running the same project in each tool, come in the next version and will be labelled as such.

  • 40%

    Result for the use case

    Do you reach something that works for this goal, without detours?

  • 20%

    Real cost

    Entry price and whether the bill is predictable. Credits and tokens count against a tool.

  • 15%

    Exit

    Can you export the code and carry on elsewhere, or are you locked in?

  • 15%

    Learning curve

    Time to a first result for the person this case is for.

  • 10%

    Maturity

    Product stability, documentation and community.

Changes that move a ranking

We only publish a launch or a change when it affects which tool you should pick.

  • Nov 2026

    Cursor changes its plans

    Individual plans are now $30, $100 and $200 a month. The old $20 Pro stays as a legacy plan. Source: Dupple

  • Jun 2026

    Windsurf is now Devin Desktop

    Cognition retired the Windsurf brand. Existing plans and extensions carried over; the Pro plan had risen from $15 to $20. Source: Noqta

  • Feb 2026

    v0 is no longer frontend-only

    It added Git integration, a VS Code-style editor, database connections and agent workflows. Source: P. Pillitteri
